# Registro de decisiones de arquitectura

Cada archivo documenta una decision con su contexto, las alternativas
descartadas y sus consecuencias —incluidas las incomodas—.

El proposito no es justificar lo hecho, sino que quien llegue despues entienda
**por que** algo esta como esta antes de cambiarlo. Una decision cuyo motivo se
perdio se revierte por accidente.
